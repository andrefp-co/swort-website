# swort-website

Starter for a SWORT Aerospace web app, built on Next.js. It is not developed past the starter page; the live company site is [swort.net](https://www.swort.net).

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Stack

Next.js 16, React 19, TypeScript and Tailwind CSS.
